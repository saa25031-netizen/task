GitHub Pages ＆ Firebase 設置ガイド

ご提供いただいた設定情報をコード内に埋め込んであります！

この HTML ファイル単体で GitHub Pages に設置するだけで即座に動かすことができます。

1 GitHub Pages での公開手順

  1. GitHub に新しいリポジトリ（例: chokubai-app）を作成します。
  2. このソースコードを index.html という名前でリポジトリにコミット＆プッシュします。
  3. GitHub リポジトリの Settings > Pages を開き、Source を Deploy from a branch (main) に設定して Save します。

2 Firebase コンソールでの必要な設定（重要）

① Googleログインの有効化

Firebase Console > Authentication > Sign-in method で Google を有効（Enabled）にしてください。

② 承認済みドメインの追加

Authentication > Settings > Authorized domains に ユーザー名.github.io を追加してください。

③ Firestore Database の作成ルール

Firestore Database を作成し、Rules タブで読み書き許可を設定してください（テストモード推奨）。
